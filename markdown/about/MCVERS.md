# Supported Minecraft versions

With each new Minecraft release comes the question: *Will it play nice with AngelAuraAmethyst?*

Thanks to the hard work from AngelAuraMC, both the Android and the iOS port now cover most Minecraft versions...

...with some small exceptions that will be listed below.

## Android
Current issues, as of the LTS release, as of writing this:

- 3d shareware build is broken with gl4es due to shader compilation errors.

## iOS

Current issues, as of the LTS release, as of writing this:

- 1.21.6 does not run on iOS

(*) - To fix these issues, please use [the most recent github actions developer build](https://nightly.link/AngelAuraMC/Amethyst-iOS/workflows/development/main/net.kdt.Amethyst-ios.ipa.zip).
