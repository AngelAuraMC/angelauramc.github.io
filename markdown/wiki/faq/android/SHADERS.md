# Shaders
The Mobileglues renderer brings up a decent shader compatibility, which means Amethyst now supports shaders made for Iris or Optifine. Here are a few list of shaders that work on Mobileglues. Do note that sodium and iris are still not supported. 

You can refer to [here](https://github.com/MobileGL-Dev/MobileGlues-release/blob/main/CompatibleShaders.md) or [here](https://github.com/MobileGL-Dev/MobileGlues-release/blob/main/ShaderSupportMatrix.md) for more information regarding shader support accross different devices. We cannot certainly state what shaders works and what doesn't on your specific device as there isn't enough data so if you face any issues please report them to Mobileglues team [here](https://github.com/MobileGL-Dev/MobileGlues-release/tree/main) (Please read instructions mentioned in the readme)
