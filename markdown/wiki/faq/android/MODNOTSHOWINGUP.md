# My mods don't show up in-game
There can be multitude of reasons behind why mods sometimes won't show up. Some of them include:
1. Incorrect or absent Modloaders: Make sure you have installed correct mods for correct modloaders (fabric mods won't show up on forge) this is obvious but happens surprisingly often.
2. Permission denied: Please check the log file. In case you find yourself getting "Permission denied" on all of your files, please do not cut the mods, copy them instead.
3. Incorrect file path: If a custom path is set in Profile options (pencil button), make sure your mods are in your custom path.
