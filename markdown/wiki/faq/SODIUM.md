# Sodium Support on Amethyst 

Sodium is not supported due to bad mobile  graphics drivers and Amethyst renderers not fully supporting sodium features. Sodium has a killswitch that'll intentionally crash the game if running on Android.

If you want to still run sodium on Android you can head to 
Amethyst Settings → experimental stuff and then toggle the sodium switch on. You would require to solve a math equation to toggle the switch on.

Note that sodium is still not supported so if you face any performance issues, rendering issues or game crashes **you will not recieve help regarding that**. Do **not** harras the devs of sodium because it did not work on your device.
